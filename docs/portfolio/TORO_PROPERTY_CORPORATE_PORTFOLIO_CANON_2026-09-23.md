## 1. Governance rule

TORO must never use one label interchangeably for a legal entity, a physical property, a brand, a debt, a project or a managed external asset.

Minimum identity for material property facts:

`property / right -> legal holder or claimant -> legal entity/person -> source -> date -> confidence -> unresolved gap`

A folder name, payer, project nickname or shareholder relationship does not prove title.

1. source account,
2. economic counterparty,
3. property/project,
4. legal entity or person,
5. nature: OPEX / CAPEX / acquisition / financing / repayment / distribution / intercompany,
6. source document,
7. confidence and reconciliation status.
